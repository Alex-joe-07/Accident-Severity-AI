Model Replacement Step-by-Step Guide

  1. Train your new model and save artifacts into v5 model/model/.
  2. Create backend/adapters/v5_adapter.py inheriting from BaseModelAdapter.
  3. Set ACTIVE_MODEL_VERSION = "V5" in backend/config.py.
  4. Restart Flask server — the UI automatically interacts with V5 without a single line of frontend code change.
